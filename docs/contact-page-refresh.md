# Start a project refresh

The /contact page now follows introduction → Share/Review/Align → project brief → concise FAQs → work/process links. The shared horizon and fonts remain intact.

ContactExperience supplies a distinct split introduction, truthful next-step copy, finite reduced-motion-aware entrances and a single Morrow Ritual owned-concept image trial beside the brief. The image stacks above the form on mobile; no other page received this visual trial.

ProjectInquiryForm now groups goals/project type, approach/budget/timing, then contact details. It preserves inquiry submission, query-carried route/type/reference, currency and campaign tracking. Labels, error descriptions, first-error focus, submission cleanup, privacy copy and a focused receipt replace the old unlabeled controls and unsupported 24-hour response guarantees. Pricing and website timelines come from OFFERS; applications are explicitly subject to scope review.
