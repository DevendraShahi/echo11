# Echo11 Phase 4 — art direction ("Signal & Structure")

**Diagnosis (from the live pages, desktop + mobile):** the shell is competent but reads generic. Every section opens the same way (big left heading + mono paragraph + content), the hero is fully centered with the wave field washing behind the text, expertise is a four-card grid of identical boxes, and project imagery is shown dimmed and desaturated until hover — so the work looks quieter than the studio claims.

**Direction**
- **Signature moment:** the hero wave field, framed as a bounded artifact panel beside the headline instead of a full-bleed wash behind centered text. Everything else stays quiet; cyan is punctuation, not atmosphere.
- **Type hierarchy:** display = Syne, tight tracking, clamp 2.6rem → 6rem, left aligned with deliberate line breaks. Reading = Syne 17–18px/1.65 at a 60–68ch measure. Meta = JetBrains Mono, uppercase, 11–12px, tracking 0.18em (section index, labels, counters).
- **Grid:** 12-column container with a persistent left **meta rail** (`01 — Capabilities`) that aligns across sections; content sits right of it on desktop and stacks above it on mobile. This replaces the repeated "heading + paragraph" opening with one consistent editorial device.
- **Rhythm:** alternate density — tight hairline capability band → open capability index → dense full-color work band → tall process statement → closing CTA. Section padding varies 20/28/32 units rather than one value everywhere.
- **Project framing:** double-bezel media (outer hairline shell + inner frame), 16:10, full colour, object-top, with an in-frame meta bar (index, title, live link). Rows carry index, title, category/year and an explicit case-study affordance.
- **Cyan discipline:** index numerals, the active row marker, one primary CTA per view, and a single hairline accent. No stacked glows; the `/work` radial wash is reduced to a small corner gradient.
- **Mobile:** its own composition — meta rail as a compact top label, headline re-wrapped, hero panel full width below the copy, capability index rows with title + one-line summary, work rows that expand to a full-width media panel with both actions.
