# About handover artwork — first marketing concept

Asset: public/images/brand/echo11-client-handover-v1.png.

Message: Built together. Now in your hands. The client receives an organised project folio and access key alongside a matching desktop/mobile website and a content archive. The scene communicates shared understanding, ownership and continued confidence rather than celebration, sales pressure or a generic handshake. This is a conceptual illustration, not an actual team/client depiction.

Generated with the built-in image tool. Prompt direction: premium human editorial handover scene, precise workspace illustration, warm natural body language between equal collaborators, client-side website/mobile/content archive/project files/access; off-white and charcoal with selective cyan, true transparency, no captions or fake metrics. Requested 4096×4096; actual native resolution must be used as the factual output size, not described as 4K.

Applied to About’s dedicated #ownership section after the standards. The previous ownership principle moved into this fuller explanation: organised work, account access/responsibilities, and separately scoped ongoing care. Desktop uses illustration left/copy right; mobile puts the copy first. The image is contained, uses a finite reduced-motion-aware entrance, and retains its transparent background. The approved perspective workshop and its hover interaction remain unchanged.

User rejected the handover illustration. It is no longer rendered on About. The ownership section is now typographic, with its headline/lead and handover details in two columns on desktop and stacked on mobile. The asset remains unused for reversible history.
